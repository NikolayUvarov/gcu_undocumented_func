## Seen before the audit

1. **The "Current state" table of [ROADMAP.md](../ROADMAP.md) (section 2) is out of date** and contradicts its section 3:
   - stage II reads "Partial": capabilities without generations, no revocation, no IDL, although C1–C8 were done on 2026-10-03 and 10-04;
   - stage III reads "no VirtIO", although VirtIO drivers exist;
   - stage I reads "fixed tables, not per-owner quotas", although K4 is done.

   It understates rather than overstates, but a reader gets a wrong picture.
2. **The image packager still lists programs before it builds** ([scripts/make_usb_image.py:29](../scripts/make_usb_image.py)). `APPLICATIONS` is computed when the script is loaded, before `02_build.sh` runs. In a clean checkout the first `04_make_usb_image.sh` therefore packs no programs, and new programs are missed in an existing one. Its own `check_image` checks the same list, and CI builds and packs in separate steps, so neither notices. Found on 2026-10-08 while building an image for the Mac; no issue records it and the code has not changed.
3. **The Mac's run is not in `main`**, and the profile on `main` names no physical machine.
4. **The local gate cannot run on the maintainer's WSL.** `scripts/ci_local.sh` needs a Linux `qemu-system-x86_64`, which is not installed there. GitHub CI covers it while it runs.
5. **Pace.** Up to about 100 commits a day from several agent sessions, with little review outside them.
