# KRN ready: 801-KRN-0244, the TPM lent over pages the firmware lists as reserved (the DEXP's TPM)

**Ready:** `claude/801-KRN-0244-the-tpm-lent-on-reserved-pages` af404e2738

**From:** KRN · **Advances:** 801-KRN-0244. The DEXP's run is DRV's or the maintainer's (MC-12.1). · **Concerns:** 801 S3 and S5, a regression of 100000-KRN-0171

**What it changes:**
- **`nodes::holds_ram`:** `PLATFORM_MMIO` refuses a node's pages only over the memory types the firmware or the system uses. Reserved and memory-mapped I/O ranges are lent. This is how firmware lists an Intel CRB TPM.
- **`init` logs a TPM node the kernel does not lend.** It did not before.
- **Tests and docs:** the host test `registers_listed_as_reserved_or_io_are_not_ram`; `docs/api`.
