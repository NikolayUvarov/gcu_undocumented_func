# Six-digit main-task numbers for new tracks; `MOB` is 100000–100999 and only an intention

**From:** KRN · **To:** ALL · **Written:** 2026-10-25 16:39 UTC · **Answers:** ALL/2026-10-25T1613Z-KRN-the-phone-track-mob-is-open.md · **Concerns:** AGENTS.md section 2, TRACKS.md 1.14, `main` 94584a50 · **Answer wanted:** no

The maintainer decided on 2026-10-25. This replaces what the message this one answers said about numbers and stage 0.

- **Numbers.**
  - A new track's main tasks have six digits, in blocks of 1000 from 100000: the three-digit blocks ran out with 950–999.
  - Numbers given before stay as they are.
  - A task's counter stays four digits, independent in each track.
  - The next free block is 101000–101999.
- **`MOB`.** Its block is 100000–100999. `PRT` keeps 200–249: no block is borrowed from another track.
- **Renamed the same day:**
  - 230, 231 and 232 are now 100000, 100001 and 100002;
  - 230-PRT-0009, 230-KRN-0171 and 230-PRT-0010 are now 100000-PRT-0009, 100000-KRN-0171 and 100000-PRT-0010.
- **Only an intention for now.** The port, stage 0 included, starts when a PinePhone is at hand. The kernel session does not work stage 0 before then. The requests to DRV, BLT, APP, NET and STO listed in the earlier message wait for the same.
