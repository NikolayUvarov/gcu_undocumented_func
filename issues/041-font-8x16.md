# 041 — 8×16 font with Cyrillic and box drawing (tools F2)

**Type:** tool · **Owner:** tools track · **Priority:** P1 · **Status:** open · **Roadmap:** track G, T0

## Problem

`common/font.rs` has 64 glyphs (ASCII 32–95): no lower case, Cyrillic or box drawing.

## Plan

- An 8×16 font covering ASCII, Cyrillic and box drawing, generated by a script from a font with a recorded licence (decision 4 of the plan); `gfx::Screen::text` draws UTF-8.

## Acceptance criteria

- A screendump in QEMU shows Cyrillic and box drawing.
