# 033 — 8×16 font with Cyrillic and box drawing

**Type:** feature · **Priority:** P0 · **Status:** open · **Blocked by:** — · **Roadmap:** track G, tools plan F2

## Problem

`common/font.rs` has 64 glyphs (ASCII 32–95): no lower case, no Cyrillic, no box-drawing or block characters. Text tools need all of them; the UI must be English and Russian (track G).

## Plan

- Take a free font: Terminus 4.49.1 (`ter-u16n.bdf`, 8×16, SIL OFL 1.1, © Dimitar Toshkov Zhekov). The OFL allows embedding with software; a subset is a modified version and may not use the reserved name "Terminus Font", so the subset is called **MIND Mono 16** and keeps the copyright and the licence.
- `scripts/font_gen.py`: `--subset <bdf>` writes the subset `fonts/mind-mono-16.bdf` (ASCII, Latin-1, Cyrillic U+0400–U+045F and U+0490–U+0491, general punctuation, arrows, №, box drawing U+2500–U+257F, block elements U+2580–U+259F, geometric shapes, U+FFFD); without arguments it generates `common/font16.rs` from the subset; `--check` fails if the generated file is stale.
- `common/font16.rs`: sorted code points and 16-byte bitmaps, `glyph(char) -> &[u8; 16]` (binary search; ASCII directly; unknown → U+FFFD).
- `fonts/OFL.txt` and `fonts/README.md`: origin, version, SHA-256 of the source archive, what was changed.
- `mind::gfx::Screen::text16` draws UTF-8 text with it.

## Acceptance criteria

- Generator freshness test; host test that every subset range is present and lookup works.
- A screendump shows Cyrillic and box drawing drawn by a program.
