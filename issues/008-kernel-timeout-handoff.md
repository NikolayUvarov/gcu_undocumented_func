# 008 — Передача управления в userspace по таймауту (а не только по клавише)

**Тип:** feature · **Приоритет:** низкий · **Статус:** open
**Затрагивает:** `kernel/src/main.rs`

## Расхождение с handoff

Handoff: ядро «по истечении задержки (или по нажатию клавиши) передаёт управление в Userspace». Код (`kernel/src/main.rs:29-32`): переход только по сканкоду `0x39` (пробел); никакого таймаута нет — без нажатия ядро крутит круг бесконечно.

## План

1. Минимально: счётчик кадров `time`; при `time >= N` (например, 300 кадров ≈ несколько секунд на `nop`-задержке) — вызывать `app_entry`. Показывать обратный отсчёт (после [007](007-kernel-font-and-primitives.md)).
2. Правильно: после [004](004-apic-idt-interrupts.md) — по тикам таймера, а не по кадрам.
3. Реагировать на любую клавишу make-code (не только пробел), игнорируя break-коды (`>= 0x80`), и сбрасывать буфер контроллера перед стартом (`while status & 1 { in 0x60 }`).

## Критерии готовности

- Без нажатия клавиш через заданное время появляется квадрат app.
- Нажатие любой клавиши ускоряет переход.
