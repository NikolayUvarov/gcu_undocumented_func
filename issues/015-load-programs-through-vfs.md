# 015 — Загрузка программ через VFS вместо RAMFS загрузчика

- Тип: feature · Приоритет: высокий · Статус: открыто · Блокируется: —

## Проблема
Загрузчик по-прежнему читает все `PROGRAM_FILES` в память до ExitBootServices. `vfs_server` уже читает диск, но ядро запускает программы только из образов загрузчика.

## План
1. Загрузчик передаёт только ядро и `BOOT_SERVICES`.
2. Системный вызов `SPAWN_IMAGE(мандат памяти, имя)`: ядро разбирает ELF из буфера, выданного процессом.
3. Пользовательский загрузчик программ (или шелл в ring 3) читает ELF через `mind::fs` и вызывает `SPAWN_IMAGE`; `RUN` обращается к нему по IPC.

## Критерии готовности
`RUN <name>` запускает файл с диска, которого нет в `PROGRAM_FILES`; ядро не хранит образы приложений.
