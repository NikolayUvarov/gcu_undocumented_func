# The reference prototype of the track `NRL`

`qwen-spline-lab-v0.1.0.zip` is Qwen Spline Lab v0.1.0, the Python/PyTorch prototype that the track `NRL` ports to Rust ([issue 900](../../issues/900-neural-representation-lab.md), section 3.1).

- **SHA-256:** `5e27aab03013e16ac447f12e7093b39ca36167fb20b9b74368661ea425a38b25`.
- **Licence:** MIT, "Qwen Spline Lab contributors" (its `LICENSE` inside the archive; [THIRD_PARTY.md](../../THIRD_PARTY.md)). No model weights and no third-party code inside.
- **Kept unchanged.** It is a reference for differential tests and for the five representations' semantics, never built or run by this repository's scripts, and never copied into an image.
- **Its own test status** (`docs/TEST_STATUS.md` inside it) is the delivery's historical protocol of 2026-10-22, not a run in this repository.

To read it, unpack it into a scratch directory outside the repository, and run nothing from it without reading it first.
