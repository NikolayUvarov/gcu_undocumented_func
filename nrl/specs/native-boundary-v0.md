# Portable runtime boundary v0 — T11 preparation

Internal linked Rust API: `nrl-runtime` version 0, no_std/no_alloc/forbid unsafe. This is not an IPC wire format, `nn.wit`, native MIND adapter or authenticated parser. APP's nnd must provide those and execute native tests before T11 closes (900-NRL-0017, requests-APP.md).

The first portable family is the existing checked feed-forward graph: affine, five gated representations, SiLU, ReLU, add and shared/tied objects. A trusted importer constructs checked borrowed kernel views and a topological plan bound to the verified complete model ID. Model data is immutable while borrowed. No model file path, filesystem, host process, heap allocator, worker creation or Rust ABI crosses a domain here. Trait implementations are trusted compute code and must have stable sizes/costs; arbitrary trait implementations are not a sandbox.

Caller-owned workspace holds one row's graph values plus maximum kernel scratch; all rows write to separately bounded caller output. Graph nodes/widths/total workspace and per-model batch limits are checked before execution. Every session binds one service-minted owner token and model ID. The service must authenticate the token from its channel/capability, keep each session/output/workspace separate and check loaded-model integrity. A numeric ID supplied by an untrusted client is not authentication.

Session policy bounds cumulative rows, logical work units and requests, workspace/output values and absolute monotonic deadline. Work units are a declared algorithmic accounting policy, not CPU cycles or FLOPs: supported host kernel views use stored numeric values plus fixed activation/output allowances. Completed node work is charged before execution; started rows/requests remain charged after failure/cancellation. Upfront insufficient-budget and wrong-owner/model requests do not execute. Kernel numeric failure/clock reversal poisons only that session; cancel/deadline closes it. Callback checkpoints occur before the request, each row/node and publication; a single checked kernel is the cancellation granularity. This is cooperative and does not replace service/kernel preemption or hard CPU/device quotas.

Transient workspace is cleared on every return; output is cleared on every error, including cancellation after earlier rows. The caller's input and immutable model remain unchanged. Resource/identity/input-shape refusals leave the session reusable; terminal compute/clock/cancel errors require a new session. Session counters and clock persist across requests.

Host package bridging and policy reports exercise the same portable executor, but their evidence is explicitly host-only. Both bare-metal rlibs establish compilation only. Required native integration remains: APP nnd/IDL/parser sessions, authenticated owner/model binding, native memory/time/worker/cancellation and native standalone-model/two-client/failure tests on a named configuration. The trained language decoder/cache profile is not silently covered by this stateless graph executor.
