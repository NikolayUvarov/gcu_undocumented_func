# AdamW and refreshed recovery v0

This host profile serves 900 T07/T10 and 262 stage 4. It adds `nrl.optimizer/0`, `nrl.optimizer-state/0`, `nrl.adaptation-config/0` and checksummed `nrl.adaptation-checkpoint/0`; existing SGD profiles are unchanged distinct experiments. Unknown fields/versions are refused. No OS service interface changes.

AdamW uses `m=beta1*m+(1-beta1)*g`, `v=beta2*v+(1-beta2)*g*g`, bias correction by the one-based step, `p *= 1-lr*decay`, then `p -= lr*m_hat/(sqrt(v_hat)+epsilon)`. Decay applies to every supplied trainable tensor, including biases; spline grids and retained-channel mappings stay fixed. Max 512 named tensors, 262144 values, 256 steps. Parameters, gradients and moments must be finite, second moments nonnegative, exact inventories match. A canonical parameter identity binds continuation to the supplied weights. Failed optimizer updates change neither weights nor state. Config, step, both moments and current weights are serialized, never reconstructed from an approximate restart. Hashes provide integrity, not authenticity.

Recovery refreshes original teacher FFN targets on the current student's **train** trajectories once per optimizer step; replaced layers update simultaneously. Attention, tokenizer, original weights and all other layers are frozen. A complete fresh-document validation language pass selects the earliest minimum NLL including step zero. No test trajectory feeds fitting or selection. This is local FFN training, not full decoder loss backpropagation, LoRA, QLoRA or mixed precision.

`compare-adaptation BASE INITIAL CORPUS CONFIG NEW_DIRECTORY` runs AdamW and a same-rate/step/data/initialization SGD control; the latter has no moments or decay. Both use their own refreshed trajectories. Checkpoints, selected complete decoder packages and dense/initial/AdamW/SGD validation/test reports are saved. Frozen validation-NLL and actual-package-ratio limits produce a dense fallback. The package still retains original weights; effective parameter reduction is not disk or RSS reduction. Repeated host timing belongs to the shared benchmark command, not this optimizer comparison.

`train-adaptation BASE INITIAL CORPUS CONFIG NEW_CHECKPOINT UNTIL`, `resume-adaptation BASE CHECKPOINT NEW_CHECKPOINT UNTIL`, and `export-adaptation BASE CHECKPOINT NEW_MODEL` support interrupted work without Python. The saved fixture `adaptation-v0/optimizer-oracle.json` is independently generated by pinned PyTorch 2.10.0 float64 AdamW, foreach/fused disabled. Gradients vary across steps; moment and parameter comparisons cover bias correction, epsilon and decay. Resume tests compare exact full states and verify that changing test text does not change fitted weights or validation selection.
