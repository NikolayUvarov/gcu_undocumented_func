# Prepared decoder experiment v0

Serves 900 T12 and MC-12.1–12.3, MC-12.9. `nrl.optimization-study/0` fixes exact model/corpus, repetitions/work limits and numerical/latency acceptance before measurement. `nrl.optimization-report/0` records both implementations explicitly; it is separate from generic T08 comparison reports.

The reference reconstructs/validates an immutable FFN block and allocates scratch for each token/layer. The candidate constructs the same checked borrowed dense/patch blocks and scratch once per document, then reuses them. Immutable Rust borrowing preserves checked weights/grids/factors; operation order, source data and policy are identical. All finite-output/input checks remain. No unchecked constructor, unsafe code, weight mutation, lower precision or new arithmetic kernel is introduced. Public transactional `step` still clones/commits state only on success. This optimization covers full-sequence forward/trace, not incremental generation latency.

The component experiment measures original layer-zero FFN on actual train inputs: reference validates/allocates per row, candidate reuses a checked view/scratch. It isolates this cost and does not by itself establish a model gain. Full measurements include candidate preparation, use fresh causal state per validation document, same scalar f64 model/inputs/executable/host, warmups, alternating AB/BA paired order and raw min/median/p95 distributions. Quality comparison uses full logits, argmax and mean NLL on every declared split. No parameter is trained or chosen from held-out data.

Decoder work includes both quality passes over all splits, both measured/warmup paths on validation and explicit train/validation calibration prefixes. Component FFN work is recorded separately. All counts are preflighted against bounded study/model/corpus inputs. The fixed example uses two warmups and seven repetitions, limits absolute logit/NLL differences to 1e-12 and accepts an observed host experiment only if candidate p95 is strictly below reference minimum and all quality checks pass. This nonoverlap criterion is not a statistical test or a target guarantee. Negative/noisy outcomes are retained. Default reference execution remains in place until accepted measurements justify a change.

CLI: `profile-decoder MODEL CORPUS STUDY NEW_REPORT`. Direct linked Rust operations `forward_reference`, `forward_prepared` and `trace_prepared` allow numerical controls. Model/artifact numerical policies and identities do not change; implementation/executable identity belongs to the experiment. Repeated timing can vary. Native/accelerator/parallel/generation and physical-memory/compression results are outside this profile and remain separate work.
