# Complete supported-model QSL binding v0

900 T04. The external `qwen-spline-lab-overlay-v1` is still imported byte-for-byte by the existing strict F32 tensor bridge. A separate `nrl.qsl-decoder-binding/0` binds every original layer ID to the same explicit layer in an exact dense `llama2c-f32-v0/0` decoder. All source FFN original widths and input/output dimensions must match, and all overlay entries must be used exactly once. There is no arbitrary layer remapping or partial silent import.

This supported base profile declares `base.fingerprint_policy=nrl-decoder-model-id/0`, `model_type=llama2c-f32-v0/0` and an exact NRL base model ID, which binds checked unchanged weights, tokenizer, configuration, numerical policy and provenance. The binding also pins the QSL artifact ID. The original QSL writer accepts such explicit base metadata. **This does not verify a Hugging Face/Qwen model_fingerprint**: those source architectures and `qwen-spline-lab-standalone-v1` remain explicitly unsupported. A supported full-model bridge is not a universal Qwen importer or closure of every future T04 format.

`nrl.qsl-decoder-overlay/0` contains the immutable original QSL manifest/weights, their lengths/hashes, binding, caller's licence and resolved full model ID. It requires the separately supplied exact base for execution. Loading recomputes the complete import and checks the resolved identity; filenames are fixed, input symlinks and unknown versions/fields are refused. Original declared base/detail/environment metadata and mapping remain in source records. Hashes are integrity checks, not signatures or licence authenticity.

`bind-qsl-decoder BASE QSL BINDING LICENCE NEW_OVERLAY`, `check-qsl-decoder BASE OVERLAY`, `run-qsl-decoder BASE OVERLAY TEXT NEW_PROBE`, and `export-qsl-decoder BASE OVERLAY NEW_MODEL` provide the round trip. Standalone export is the existing `nrl.decoder/0` format with all unchanged source weights, tokenizer and replacements. It runs after deleting original QSL/overlay/base directories. Its source notices retain the complete bounded original manifest and explicit binding. Retaining original weights means no physical disk savings are implied.

The independent fixture uses the unchanged archived QSL writer/loader to transform four actual TinyStories 260K FFNs (pruned, linear, cubic, original-width rank-4 SVD). A vectorized PyTorch decoder checks **full vocabulary logits and greedy tokens**, including all unchanged attention/normalization/RoPE/tokenizer/head components. The fixture measures numerical interoperability only, not accepted compression or useful quality. Existing dense/five-representation block tests remain separate. The artifact's 16384-value block bound remains unchanged; unsupported larger blocks/architectures are refused rather than broadened silently.
