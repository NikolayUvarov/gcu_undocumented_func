# Frozen larger representation study v0

900 T08/T09/T10. `expanded-v0` fixes **48 TinyStories source-validation story prefixes**, split 24/12/12 for this experiment. Up to 384 source UTF-8 bytes per story are retained at character boundaries. Selection orders full-story SHA-256 digests, excludes duplicate normalized prefixes and takes 48; story identities do not cross experiment splits. This is a larger same-genre study, not a full-dataset or unseen-pretraining/general-language benchmark. Semantic near-duplicates beyond these checks remain unknown.

Source: [TinyStories by Ronen Eldan and Yuanzhi Li](https://huggingface.co/datasets/roneneldan/TinyStories/tree/f54c09fd23315a6f9c86f9dc80f725de7d8f9c64), `TinyStories-valid.txt`, 19447282 bytes, SHA-256 `94e431816c4cce81ff71e4408ff8d3bda9a42e8d2663986697c3954288cb38b4`. The publisher declares **CDLA-Sharing-1.0**. The modified corpus prominently identifies changes and retains source attribution, licence name/link/full text and pinned source card. `source.json` records the original and all derived input checksums. Corpus data is CDLA-Sharing-1.0, not the repository's default dual code licence.

Before evaluation, `study.json` freezes eight plans (four single-layer width-32 controls, two mixtures and width-64 pruned/linear controls), 128 calibration rows, 16 local SGD steps, rate 0.002, validation NLL increase <=0.25, actual package ratio <=1.5, one warmup/three timed passes. `adaptation.json` freezes eight refreshed AdamW/SGD recovery steps from the same mixed plan, rate 0.0002 and 128 train rows. These inputs are committed before the experiment runs.

`python3 nrl/tools/run_expanded_study.py --executable nrl/target/release/nrl-lab --output NEW_DIRECTORY` uses ordinary Rust CLI commands only: checked dense import, complete plan search, paired optimizer recovery, measured validation of both recovery arms and all-candidate held-out reports. A global selection file is written before all-candidate test reporting; eligibility uses only validation quality, real package bytes and recorded nonoverlapping timing ranges, with dense fallback. Previous search/optimizer commands may already emit their own frozen-selection test diagnostics; no test metric is consumed by global selection. Python does orchestration/hashing, not numerical execution. Raw command exit codes/times and exact executable identity accompany the results.

Default NRL checks validate corpus, pinned data identity, real tokenizer and plan contracts. `bash nrl/tools/check.sh --expanded` also repeats this entire larger study. Outputs must be new paths. Normal execution needs no network or Python ML library. To regenerate the corpus, run `prepare_expanded_corpus.py --source RAW_FILE --output CORPUS [--check]`; optional `--download` fetches only the pinned source into a new file and verifies its exact size/hash. The published corpus and the full agreement suffice for ordinary offline replay.
