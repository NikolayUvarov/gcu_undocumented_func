# Language calibration and resumable local training v0

**Edition:** 0 (2026-10-26) · **Task:** [900-NRL-0013](../../issues/900-NRL-0013-calibration-and-resumable-local-training.md) · **Scope:** scalar f64 replacement fitting for the bounded trained decoder. Existing decoder/block formats and mathematical bounds are unchanged.

`nrl.language-data/0` declares a source/licence/notices record, at most 64 documents, unique stable document/group IDs, explicit nonempty train/validation/test splits and a token limit (2..512) no larger than the decoder context. IDs are 1..128 ASCII alphanumeric or `_.-`. Each UTF-8 document has 1..4096 bytes and no NUL. Related groups, exact text and equal token sequences never cross splits. All documents are validated/tokenized before activations. The supplied relationships are declarations, not an automatic statistical-independence detector. Byte-BPE uses BOS, no added EOS or truncation; language targets are shifted text tokens, and only the preceding prefix is executed. This policy becomes a comparability key in T08.

`nrl.calibration/0` binds the exact unpatched teacher model, corpus ID, layer, dimension and `frozen-original-teacher-input/0` protocol. Only train and validation normalized FFN inputs/actual outputs are collected. Each part takes at most its explicit positive 1..256 row cap, in supplied document/token order, with actual document/group IDs and token prefixes retained. Later omitted rows/documents are not silently counted. Test activations are absent. Calibrations validate shapes, finite values, split membership, sampled rows and identity; teacher verification also checks token provenance and recomputes the paired inputs/targets. A hash does not authenticate an unknown author.

`nrl.transform/0` describes `pruned`, `spline-linear`, `spline-cubic` or `svd`, width 1..64, explicit grid/rank settings, with unused settings required to be zero. Initialization uses original teacher weights and train activations only. Every candidate at a common width uses identical activation-energy channel ranking, stable source-index tie breaking and an ascending retained map. Splines use train gate-projection minima/maxima with a 5% margin (at least 1e-6), current SiLU values at knots and the existing linear-tail/Hermite mathematics. Fixed grids do not train. SVD first applies the declared channel reduction, then factorizes those selected matrices; it is not an SVD of the original full 172-channel source. The retained source map stays explicitly in the training record because the existing factor artifact has no selection field. Dense control remains the original decoder, not an oversized small artifact. Existing artifact value/byte limits and the SVD dimension/sweep limits remain enforced, including intermediate and resulting-factor capacity.

`nrl.local-config/0` supplies the transform, 1..64 full-batch steps, a positive finite fixed learning rate and an output source/licence/notice declaration. Its hash is derived by the tool, so the input source hash is absent and its identifier leaves room for a 65-byte hash suffix. One derived source slot is reserved before training. All projection/factor/spline/bias parameters supported by the chosen artifact train with existing analytic gradients, initialized independently of validation/test. Each step is transactional. Validation MSE alone selects the earliest best step, including step zero. MSE/NMSE, MAE, maximum absolute error, target energy/near-zero flag and actual spline out-of-grid fraction are reported. NMSE divides by the block target's own mean energy, floored at 1e-12; it is not normalized by the residual stream.

`nrl.local-state/0` contains complete frozen calibration data, config and IDs, source hidden width, retained map, initial/current/best artifacts, completed and selected step, complete train/validation history, optimizer ID, data order and next cursor. SGD is stateless: no momentum/decay; the explicit RNG state is none, initialization is deterministic and rows never shuffle. The next cursor is zero at full-batch boundaries. `nrl.local-checkpoint/0` binds the typed canonical payload with SHA-256 and bounds JSON to 16 MiB. Versions, unknown/duplicate fields, payload integrity, finite shapes/metrics, fixed geometry/grids/mapping, order/step/selection and snapshot metrics are checked on load. No hidden optimizer or random state is omitted. Hash integrity is not authenticity or a proof of arbitrary historic claims.

A run can stop at a supplied absolute step up to its fixed total budget, save, load and continue. Identical same-host/executable uninterrupted versus resumed histories and weights are checked. Replay from zero is different from continuation; changing config/data requires a new run. A later failing step preserves completed valid steps, while each individual update commits only after finite output/metric checks. No equivalence is promised across backends/toolchains.

Independent CLI entries are `calibrate-decoder`, `train-local`, `resume-local`, `export-local`. Every output path must be new. Selected export rechecks the original teacher/calibration, preserves its source declarations, appends the corpus and a declaration binding the canonical checkpoint payload, and replaces that one FFN in the existing decoder package. The dense source blob is still retained and counted; no disk/RSS reduction follows. Runtime inference needs no checkpoint file, C or Python. Resource limits here are bounded rows/values/steps, not native cancellation/deadlines or process-RSS capabilities.

Independent PyTorch on real trained-model traces checks channel scores and four SGD steps. All four compressed initializers and local passes, exact resume, test-data independence, held-out split refusals, corrupt checkpoint rejection and decoder export are checked on the NRL branch. The provided corpus is a small reproducible task fixture, not representative model-quality evidence. T08 adds full task evaluation/benchmark comparison; T09/T10 add whole-model selection and adaptation to student activations. This local fit alone is not an accepted model optimization or native integration.
