# Первая загрузка на плате Allwinner: Orange Pi Zero Plus 2 H5 и Orange Pi Zero 3

**Версия:** 0.1 (2026-11-26) · **Задача:** [100004-MOB-0012](../../issues/100004-MOB-0012-the-boards-first-boot-step-by-step-and-its-run-script.md) · **Главная задача:** [100004](../../issues/100004-two-allwinner-boards-before-the-phone.md) · **Английская версия:** [allwinner-first-boot.md](allwinner-first-boot.md) (основная; эта держится в согласии с ней)

> **Ни одна плата ещё не загружала MIND Core.** Здесь шаги первого раза, написанные до того, как платы подключены. Что ожидает каждый шаг, взято из скриптов, кода и документации прошивки, а также из QEMU `virt` под UEFI U-Boot (раздел 8), а это свидетельство только для QEMU (MC-12.1). Где шаг на плате не выполнится, задача платы записывает то, что было видно.

Плата самого стенда (слово сопровождающего 2026-11-26: плата разработки с добавленными компонентами) ещё не названа ([issues-human, раздел 14](../../issues-human/README.md#14-the-two-allwinner-boards-on-the-bench)). Пока её нет, страница описывает две платы этого трека.

## 1. Что нужно

| | Orange Pi Zero Plus 2 H5 | Orange Pi Zero 3 (H618) |
|---|---|---|
| Имя в каталоге | `orangepi-zero-plus2` | `orangepi-zero3` |
| Питание | 5 В, от 2 А | 5 В, от 2 А, через USB-C |
| Консоль | UART0, 3-контактный отладочный разъём, 3,3 В, 115200 8N1 | так же |
| Память | 512 МиБ | 2 ГиБ |

Кроме платы: карта microSD от 1 ГБ, которую не жалко, и **USB-картридер** (писатель пишет только то, что Windows называет USB-диском); USB-UART адаптер на 3,3 В; три провода и резистор около 1 кОм для TX адаптера; хост (DEXP, Ryzen или MacBook под Windows или Linux) с терминалом (PuTTY; `picocom` или `screen`).

## 2. Карта

```bash
./build-and-write.sh --list                             # USB-диски и их номера
./build-and-write.sh --board orangepi-zero3 <номер>     # или --board orangepi-zero-plus2
```

- Собирает aarch64, упаковывает образ и делает карту `dist/boards/mind-<плата>.img`: U-Boot с TF-A с 8 КиБ, разделы MIND Core с 4 МиБ.
- Печатает SHA-256 прошивки рядом с каталожным и SHA-256 карты: сохраните оба для задачи платы.
- Писатель спрашивает `ERASE <номер>` и читает карту обратно.
- **Для первой загрузки — без `--link` и `--slots`:** с ними `link.conf` содержит `uart`, линк забирает консольный UART, и у оболочки нет последовательной линии.

## 3. Подключение

- TX платы — к RX адаптера, RX платы — к TX адаптера, GND — к GND. **VCC адаптера — никогда.**
- **Порядок контактов** напечатан у разъёма и в руководстве Orange Pi к плате. Страница его не называет: он не прочитан в проверенном источнике. Сверьтесь с платой до подключения.
- Резистор около 1 кОм последовательно с TX адаптера: без питания TX адаптера (3,3 В в покое) может держать плату полувключённой через её RX.
- Имя порта: Windows — `COMn` в диспетчере устройств; Linux — `/dev/serial/by-id/usb-…`. Запишите чип адаптера, хост и порт (MC-12.1).

## 4. Первая загрузка руками сопровождающего

1. Откройте терминал на порту адаптера, 115200 8N1, без управления потоком, с записью в файл (PuTTY: Logging → "All session output"; Linux: `picocom -b 115200 --logfile console.txt /dev/serial/by-id/usb-…`).
2. Вставьте карту, включите питание.
3. Строки идут так: SPL U-Boot, баннер `U-Boot 2026.10 …` и отсчёт `Autoboot in 2 s: type stop for the U-Boot prompt` (ничего не набирайте); строки нашего загрузчика `BOOT: …` и `… IMAGES CHECKED`; строка ядра `MIND CORE KERNEL: BOARD FROM THE DEVICE TREE: …`, затем `MIND CORE KERNEL: INIT STARTED`; строки служб и приглашение `MIND> `.
4. В приглашении наберите по очереди, дожидаясь приглашения: `cpus`, `physmap`, `free`, `time`, через несколько секунд ещё раз `time`, затем `reboot`.
5. Перезагрузка: `REBOOTING...`, `MIND CORE KERNEL: REBOOT VIA PSCI SYSTEM_RESET`, затем снова баннер U-Boot.
6. Проверьте запись: `python3 scripts/board_stage1.py --file console.txt` — каждый критерий `MET` или `MISSING` со строкой, которая это показала; код выхода 0 только когда выполнены все.
7. Пришлите запись и вывод проверки, ревизию платы, SHA-256 карты, адаптер, хост и порт — для 100004-MOB-0002 (H5) или 100004-MOB-0003 (Zero 3).

**Если остановилась:** чтобы попасть в приглашение U-Boot (`=>`), наберите `stop` во время отсчёта; там `printenv` показывает настройки, `boot` продолжает загрузку. Если ничего нет — проверьте провода (TX и RX крест-накрест, GND) и скорость.

## 9. Что под риском на платах

Консоль оболочки на 16550 через байтовый канал ядра (на 16550 не запускалась); вход на EL2 (100004-PRT-0014); нет диска после загрузчика (100004-MOB-0005); нет ключа устройства без RNDR (100000-KRN-0279); сторожевой таймер A31 (100004-PRT-0015). Ничего из этого на плате не видели (MC-12.3).
